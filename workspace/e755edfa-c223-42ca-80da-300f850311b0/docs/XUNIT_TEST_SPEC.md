# XUnit Test Specification: Student Registration System (SRS)

This document outlines the exhaustive test suite for the Student Registration System (SRS). All tests are implemented using `xUnit`, `FluentAssertions`, and `Moq`.

## 1. Unit Tests (UT)

### UT-01: Valid Registration
*   **Preconditions:** Mock `IStudentRepository` and `IUnitOfWork`.
*   **Input:** Valid `StudentRegistrationRequest` object.
*   **Steps:** Invoke `StudentService.RegisterStudentAsync`.
*   **Expected Result:** Returns `StudentResponse` with generated Guid. Assert `CreatedBy` matches mock user.

### UT-02: Missing Required Fields
*   **Preconditions:** None.
*   **Input:** `StudentRegistrationRequest` with null/empty fields.
*   **Steps:** Invoke `FluentValidation` validator.
*   **Expected Result:** `ValidationException` thrown. Assert error messages for FullName, Email, and DateOfBirth.

### UT-03: Age Validation
*   **Preconditions:** None.
*   **Input:** `DateOfBirth` resulting in age < 16 or > 100.
*   **Steps:** Invoke `FluentValidation` validator.
*   **Expected Result:** `ValidationException` thrown. Assert specific age range error.

### UT-04: Invalid Email Format
*   **Preconditions:** None.
*   **Input:** Email string missing '@' or domain.
*   **Steps:** Invoke `FluentValidation` validator.
*   **Expected Result:** `ValidationException` thrown. Assert email format error.

### UT-05: Department Validation
*   **Preconditions:** None.
*   **Input:** Department string > 100 chars.
*   **Steps:** Invoke `FluentValidation` validator.
*   **Expected Result:** `ValidationException` thrown. Assert length constraint error.

### UT-06: UTC Timestamp Verification
*   **Preconditions:** Mock `DateTimeProvider`.
*   **Input:** Valid registration request.
*   **Steps:** Execute registration.
*   **Expected Result:** Assert `RegistrationDate.Kind == DateTimeKind.Utc`.

### UT-07: CreatedBy User Identity
*   **Preconditions:** Mock `IUserContext` returning "user-123".
*   **Input:** Valid request.
*   **Steps:** Execute registration.
*   **Expected Result:** Assert `Student.CreatedBy == "user-123"`.

### UT-08: Nullable Audit Fields
*   **Preconditions:** None.
*   **Input:** Valid request.
*   **Steps:** Execute registration.
*   **Expected Result:** Assert `LastModifiedAt` and `LastModifiedBy` are null.

### UT-09: Client Audit Injection
*   **Preconditions:** None.
*   **Input:** Request containing `Id` and `CreatedBy` fields.
*   **Steps:** Execute registration.
*   **Expected Result:** Assert `Id` is generated by system, not input. Assert `CreatedBy` is ignored.

### UT-10: Duplicate Email Conflict
*   **Preconditions:** Mock repository returns existing student for email.
*   **Input:** Request with existing email.
*   **Steps:** Execute registration.
*   **Expected Result:** `ConflictException` thrown.

### UT-11: Database Exception Handling
*   **Preconditions:** Mock repository throws `DbUpdateException`.
*   **Input:** Valid request.
*   **Steps:** Execute registration.
*   **Expected Result:** `ServiceException` (503) thrown.

### UT-12: String Sanitization & Email Normalization
*   **Preconditions:** None.
*   **Input:** Email " USER@Example.com ", Name "  John Doe  ".
*   **Steps:** Execute registration.
*   **Expected Result:** Assert `Email == "user@example.com"`, `FullName == "John Doe"`.

## 2. Integration Tests (IT)

### IT-01: POST /api/students Success
*   **Preconditions:** Authenticated client with `student:create` claim.
*   **Input:** Valid JSON payload.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 201 Created, Location header present.

### IT-02: 401 Unauthorized
*   **Preconditions:** No Authorization header.
*   **Input:** Valid JSON.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 401 Unauthorized.

### IT-03: 403 Forbidden
*   **Preconditions:** Authenticated client without `student:create` claim.
*   **Input:** Valid JSON.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 403 Forbidden.

### IT-04: 400 Bad Request (Malformed JSON)
*   **Preconditions:** None.
*   **Input:** Invalid JSON syntax.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 400 Bad Request.

### IT-05: 413 Payload Too Large
*   **Preconditions:** None.
*   **Input:** 20KB JSON payload.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 413 Payload Too Large.

### IT-06: 415 Unsupported Media Type
*   **Preconditions:** None.
*   **Input:** XML payload.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 415 Unsupported Media Type.

### IT-07: 429 Too Many Requests
*   **Preconditions:** None.
*   **Input:** 101 requests in 60 seconds.
*   **Steps:** Loop `POST /api/students`.
*   **Expected Result:** 429 Too Many Requests.

### IT-08: 409 Conflict (SQLite)
*   **Preconditions:** Database contains email "test@test.com".
*   **Input:** Request with "test@test.com".
*   **Steps:** `POST /api/students`.
*   **Expected Result:** 409 Conflict.

### IT-09: RFC 9457 Problem Details
*   **Preconditions:** None.
*   **Input:** Invalid payload.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** Response body matches `application/problem+json` schema.

### IT-10: SQLite Persistence
*   **Preconditions:** Clean database.
*   **Input:** Valid request.
*   **Steps:** `POST /api/students`, then query SQLite directly.
*   **Expected Result:** Record exists in `Students` table.

### IT-11: Atomicity Verification
*   **Preconditions:** Force DB error during transaction.
*   **Input:** Valid request.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** Assert 0 records in `Students` table.

### IT-12: Audit Identity Verification
*   **Preconditions:** JWT `sub` = "auth0|123".
*   **Input:** Valid request.
*   **Steps:** `POST /api/students`.
*   **Expected Result:** Assert `CreatedBy` in DB is "auth0|123".

### IT-13: Concurrent Duplicate Registrations
*   **Preconditions:** None.
*   **Input:** Two identical requests sent simultaneously.
*   **Steps:** Parallel execution.
*   **Expected Result:** One 201, one 409.

### IT-14: GET /health
*   **Preconditions:** DB available.
*   **Input:** N/A.
*   **Steps:** `GET /health`.
*   **Expected Result:** 200 OK.
