# XUnit Test Specification: Student Registration System (SRS) v1.1

## 1. Test Infrastructure
*   **Framework**: xUnit, FluentAssertions, Moq, Microsoft.AspNetCore.Mvc.Testing.
*   **Database**: Isolated SQLite in-memory/file-based database per test class using `DatabaseFixture`.
*   **Execution Command**: `dotnet test --configuration Release`

---

## 2. Unit Tests (UT-01 to UT-12)

### UT-01: Valid Registration
*   **Preconditions**: Mock `IStudentRepository` and `ClaimsPrincipal`.
*   **Input**: Valid `StudentRequest` DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert returned object has valid `Id`, `CreatedAt` is UTC, `CreatedBy` matches mock identity.

### UT-02: Missing Required Fields
*   **Preconditions**: FluentValidation configured.
*   **Input**: DTO with null/empty fields.
*   **Steps**: Execute `IValidator<StudentRequest>.Validate`.
*   **Assertions**: Assert `IsValid` is false; contains errors for missing fields.

### UT-03: Age Validation
*   **Preconditions**: None.
*   **Input**: Age 15 and 101.
*   **Steps**: Execute `IValidator<StudentRequest>.Validate`.
*   **Assertions**: Assert `IsValid` is false for both inputs.

### UT-04: Invalid Email Format
*   **Preconditions**: None.
*   **Input**: Email "invalid-email".
*   **Steps**: Execute `IValidator<StudentRequest>.Validate`.
*   **Assertions**: Assert `IsValid` is false.

### UT-05: Department Validation
*   **Preconditions**: None.
*   **Input**: Department string length 101.
*   **Steps**: Execute `IValidator<StudentRequest>.Validate`.
*   **Assertions**: Assert `IsValid` is false.

### UT-06: UTC Timestamp Verification
*   **Preconditions**: Mock system clock.
*   **Input**: Valid DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert `CreatedAt.Kind == DateTimeKind.Utc`.

### UT-07: CreatedBy User Identity
*   **Preconditions**: Mock `ClaimsPrincipal` with `NameIdentifier` = "user-123".
*   **Input**: Valid DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert `CreatedBy` property equals "user-123".

### UT-08: Nullable Audit Fields
*   **Preconditions**: None.
*   **Input**: Valid DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert `UpdatedAt` is null and `UpdatedBy` is null.

### UT-09: Client Audit Injection
*   **Preconditions**: None.
*   **Input**: DTO with hardcoded `Id` and `CreatedBy`.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert resulting entity `Id` is generated by DB, not client; `CreatedBy` is from Auth context.

### UT-10: Duplicate Email Conflict
*   **Preconditions**: Repository configured to throw `DbUpdateException` (unique constraint).
*   **Input**: Valid DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert `ConflictException` is thrown.

### UT-11: Database Exception Handling
*   **Preconditions**: Repository configured to throw `SqliteException`.
*   **Input**: Valid DTO.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert custom `DatabaseUnavailableException` is thrown.

### UT-12: String Sanitization & Email Normalization
*   **Preconditions**: None.
*   **Input**: `FullName` with leading/trailing spaces, `Email` with uppercase.
*   **Steps**: Invoke `StudentService.RegisterAsync`.
*   **Assertions**: Assert `FullName` is trimmed, `Email` is lowercase.

## 3. Integration Tests (IT-01 to IT-14)

### IT-01: POST /api/students 201 Created
*   **Preconditions**: Authenticated client with `student:create` claim.
*   **Input**: Valid JSON payload.
*   **Steps**: Send POST request.
*   **Assertions**: Status 201, Location header present.

### IT-02: 401 Unauthorized
*   **Preconditions**: No Authorization header.
*   **Input**: Valid JSON.
*   **Steps**: Send POST request.
*   **Assertions**: Status 401.

### IT-03: 403 Forbidden
*   **Preconditions**: Authenticated user without `student:create` claim.
*   **Input**: Valid JSON.
*   **Steps**: Send POST request.
*   **Assertions**: Status 403.

### IT-04: 400 Bad Request (Malformed JSON)
*   **Preconditions**: None.
*   **Input**: Invalid JSON string.
*   **Steps**: Send POST request.
*   **Assertions**: Status 400.

### IT-05: 413 Payload Too Large
*   **Preconditions**: None.
*   **Input**: JSON > 16KB.
*   **Steps**: Send POST request.
*   **Assertions**: Status 413.

### IT-06: 415 Unsupported Media Type
*   **Preconditions**: None.
*   **Input**: Content-Type: application/xml.
*   **Steps**: Send POST request.
*   **Assertions**: Status 415.

### IT-07: 429 Too Many Requests
*   **Preconditions**: Rate limit configured.
*   **Input**: 21 rapid requests.
*   **Steps**: Loop POST requests.
*   **Assertions**: 21st request returns 429.

### IT-08: 409 Conflict
*   **Preconditions**: Database contains existing email.
*   **Input**: DTO with existing email.
*   **Steps**: Send POST request.
*   **Assertions**: Status 409.

### IT-09: RFC 9457 Problem Details
*   **Preconditions**: Validation failure.
*   **Input**: Invalid DTO.
*   **Steps**: Send POST request.
*   **Assertions**: Response body matches `application/problem+json` schema.

### IT-10: SQLite Persistence
*   **Preconditions**: None.
*   **Input**: Valid DTO.
*   **Steps**: POST request, then query `AppDbContext`.
*   **Assertions**: Record exists in DB.

### IT-11: Atomicity Verification
*   **Preconditions**: Force DB error during save.
*   **Input**: Valid DTO.
*   **Steps**: POST request.
*   **Assertions**: DB count remains 0.

### IT-12: Audit Identity Verification
*   **Preconditions**: JWT `sub` claim = "test-user".
*   **Input**: Valid DTO.
*   **Steps**: POST request, query DB.
*   **Assertions**: `CreatedBy` == "test-user".

### IT-13: Concurrent Duplicate Registrations
*   **Preconditions**: Two threads, same email.
*   **Input**: Two identical DTOs.
*   **Steps**: Parallel execution.
*   **Assertions**: One 201, one 409; DB count = 1.

### IT-14: GET /health
*   **Preconditions**: System running.
*   **Input**: None.
*   **Steps**: GET `/health`.
*   **Assertions**: Status 200, body contains "Healthy".
