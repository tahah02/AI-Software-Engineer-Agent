# XUnit Test Specification: Student Management System

This document outlines the comprehensive test suite for the Student Management System. All tests are implemented using `xUnit`, `Moq`, and `Microsoft.AspNetCore.Mvc.Testing`.

## Test Execution Command
```bash
dotnet test --configuration Release
```

---

## UNIT TESTS (UT-01 through UT-12)

### UT-01: Valid Registration
- **Preconditions:** Mock `IStudentRepository` and `IUserContext`.
- **Input:** Valid `StudentCreateDto` object.
- **Execution:** Call `StudentService.CreateAsync(dto)`.
- **Assertions:** Verify `CreatedAt` is within 1s of `DateTime.UtcNow`. Assert `Id` is not empty.
- **DB State:** Verify `SaveChangesAsync` was called exactly once.

### UT-02: Missing Required Fields
- **Preconditions:** None.
- **Input:** `StudentCreateDto` with null/empty fields.
- **Execution:** Invoke `FluentValidation` validator.
- **Assertions:** Assert `ValidationResult.IsValid` is `false`. Assert error count matches missing fields.

### UT-03: Age Validation
- **Preconditions:** None.
- **Input:** `Age` = 15 and `Age` = 101.
- **Execution:** Invoke `FluentValidation` validator.
- **Assertions:** Assert `ValidationResult` contains errors for the `Age` property.

### UT-04: Invalid Email Format
- **Preconditions:** None.
- **Input:** `Email` = "invalid-email-format".
- **Execution:** Invoke `FluentValidation` validator.
- **Assertions:** Assert `ValidationResult` contains error for `Email` format.

### UT-05: Department Validation
- **Preconditions:** None.
- **Input:** `Department` string length = 101.
- **Execution:** Invoke `FluentValidation` validator.
- **Assertions:** Assert `ValidationResult` contains error for `Department` length.

### UT-06: UTC Timestamp Verification
- **Preconditions:** System clock set to UTC.
- **Input:** Valid `StudentCreateDto`.
- **Execution:** Create entity via service.
- **Assertions:** Assert `entity.CreatedAt.Kind == DateTimeKind.Utc`.

### UT-07: CreatedBy User Identity
- **Preconditions:** Mock `ClaimsPrincipal` with `sub` = "user123".
- **Input:** Valid `StudentCreateDto`.
- **Execution:** Call `StudentService.CreateAsync`.
- **Assertions:** Assert `entity.CreatedBy == "user123"`.

### UT-08: Nullable Audit Fields
- **Preconditions:** None.
- **Input:** Valid `StudentCreateDto`.
- **Execution:** Create entity.
- **Assertions:** Assert `entity.UpdatedAt == null` and `entity.UpdatedBy == null`.

### UT-09: Client Audit Injection
- **Preconditions:** None.
- **Input:** `StudentCreateDto` with hardcoded `Id` and `CreatedBy`.
- **Execution:** Map DTO to Entity.
- **Assertions:** Assert `entity.Id` is generated by system, not DTO. Assert `CreatedBy` is ignored.

### UT-10: Duplicate Email Conflict
- **Preconditions:** Mock `IStudentRepository` to throw `DbUpdateException` (Unique constraint).
- **Input:** Valid DTO with existing email.
- **Execution:** Call `StudentService.CreateAsync`.
- **Assertions:** Assert `ConflictException` is thrown.

### UT-11: Database Exception Handling
- **Preconditions:** Mock `IStudentRepository` to throw `SqliteException`.
- **Input:** Valid DTO.
- **Execution:** Call `StudentService.CreateAsync`.
- **Assertions:** Assert `ServiceException` (500) is thrown.

### UT-12: String Sanitization & Email Normalization
- **Preconditions:** None.
- **Input:** `Email` = " USER@Example.com ", `FullName` = "  John Doe  ".
- **Execution:** Call service mapping logic.
- **Assertions:** Assert `entity.Email == "user@example.com"`. Assert `entity.FullName == "John Doe"`.

## INTEGRATION TESTS (IT-01 through IT-14)

### IT-01: POST /api/students Success
- **Preconditions:** Authenticated client with `student:create` claim.
- **Input:** Valid JSON payload.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 201. Assert `Location` header is present.

### IT-02: 401 Unauthorized
- **Preconditions:** No Authorization header.
- **Input:** Valid JSON.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 401.

### IT-03: 403 Forbidden
- **Preconditions:** Authenticated client without `student:create` claim.
- **Input:** Valid JSON.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 403.

### IT-04: 400 Bad Request
- **Preconditions:** None.
- **Input:** Malformed JSON (missing braces).
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 400.

### IT-05: 413 Payload Too Large
- **Preconditions:** None.
- **Input:** JSON payload > 16KB.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 413.

### IT-06: 415 Unsupported Media Type
- **Preconditions:** None.
- **Input:** Content-Type: `application/xml`.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 415.

### IT-07: 429 Too Many Requests
- **Preconditions:** None.
- **Input:** 101 requests in rapid succession.
- **Execution:** Loop `POST /api/students`.
- **Assertions:** Assert status 429 on the 101st request.

### IT-08: 409 Conflict
- **Preconditions:** Database contains student with email `test@test.com`.
- **Input:** JSON with `test@test.com`.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert status 409.

### IT-09: RFC 9457 Problem Details
- **Preconditions:** Invalid input.
- **Input:** Invalid JSON.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert `Content-Type` is `application/problem+json`. Assert `type` and `status` fields exist.

### IT-10: SQLite Persistence
- **Preconditions:** Clean database.
- **Input:** Valid JSON.
- **Execution:** `POST /api/students`, then `GET /api/students/{id}`.
- **Assertions:** Assert returned object matches input.

### IT-11: Atomicity Verification
- **Preconditions:** Force DB failure during transaction.
- **Input:** Valid JSON.
- **Execution:** `POST /api/students`.
- **Assertions:** Assert database count remains unchanged.

### IT-12: Audit Identity Verification
- **Preconditions:** JWT with `sub` = "test-user".
- **Input:** Valid JSON.
- **Execution:** `POST /api/students`.
- **Assertions:** Query DB directly; assert `CreatedBy == "test-user"`.

### IT-13: Concurrent Duplicate Registrations
- **Preconditions:** None.
- **Input:** Two identical requests sent simultaneously.
- **Execution:** `Task.WhenAll` of two POST requests.
- **Assertions:** Assert one 201 and one 409.

### IT-14: GET /health
- **Preconditions:** System running.
- **Input:** None.
- **Execution:** `GET /health`.
- **Assertions:** Assert status 200. Assert body contains "Healthy".
